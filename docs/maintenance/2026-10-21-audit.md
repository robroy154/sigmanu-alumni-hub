# Maintenance Audit — 2026-10-21

Read-only sweep of the repo, Supabase, Vercel, Resend, and Stripe (live), plus a small set of
behavior-neutral fixes on branch `maintenance/2026-10-21`. No member contact data appears in this
report; rows are referenced by UUID only.

## Summary (worst first)

1. **CRITICAL — fixed in DB.** Members could not save anything to their own `members` row. A
   hand-run table-level `REVOKE UPDATE ON members FROM authenticated` (in no migration) broke profile
   edit, photo upload, complete-profile, onboarding dismiss, and the profile/big-brother writes at
   signup and join. Live `permission denied for table members` seen in Postgres logs tonight. Fixed
   with a column-scoped `GRANT UPDATE` (migration `20261022022810`), applied with Rob's approval and
   verified.
2. **CRITICAL — fixed on branch.** Every Vercel production deploy since Aug 31 (PR #50) has failed;
   prod is serving the Aug 24 build (#49). Same root cause as #46: a Dependabot Stripe SDK bump
   changed the `apiVersion` literal type. Fixed the literal, and the auto-merge workflow now
   typechecks and builds before merging.
3. **HIGH — open.** Profile/signup validation accepts anything: every optional field is
   `z.string().optional()` with no trim, length, format, or allowed values. This is why `country`
   holds an email address, a birthday is in 1869, and states/phones/countries are inconsistent.
4. **HIGH — open (latent, payments).** Event form saves `early_bird_price = 0` for every event
   (`z.coerce.number()` runs before the `""` branch). If an admin ever sets only an early-bird end
   date, checkout charges $0.
5. **HIGH — open.** `sendSignupNotifications` is an unauthenticated server action that emails any
   address with branded mail and alerts admins. Abuse vector for domain reputation.
